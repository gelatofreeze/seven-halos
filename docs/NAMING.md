# Naming and originality log

SEVEN HALOS is intended for commercial release. New distinctive proper names get a proportionate screen before they're finalised: web searches for the same or confusingly similar names in games, entertainment and obvious trademarks. **This is not legal clearance.** A broader IP review is planned before launch.

Generic descriptive words (sword, scythe, reaper, skeleton, dust) aren't screened on their own.
